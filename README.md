# neverwood
Work-in-progress 2D roguelike.

Currently implemented:
* Keyboard and mouse controls for moving and attacking
* Basic combat and enemy AI
* Dynamic lighting and fog-of-war
* Procedurally generated enemy spawns

Planned features:
* Procedurally generated usable and equipment items
* Experience and leveling up
* Robust stat system for players and enemies
* Character classes with distinct abilities
* Many more enemy types with unique stats and abilities
* A full story campaign with many more maps to explore
